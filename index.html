maximex - Data Management Tool¶

Data import/export toolbox for:

  • IBM Maximo©
  • Maximo Application Suite
  • IBM Control Desk
  • other TPAE based products

maximex - Data Management Tool (or short maximex) previously known as:

  • Maximo Data Manager and
  • EAM Datamanagement Tool

are only different names for the same software. These product names may be used interchangeably in this user manual.
